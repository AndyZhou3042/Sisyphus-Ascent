# Development history

## 2026-11-24

### Terrain, momentum, and audio

- Reshaped the uphill terraces with steep ramps, flat landings, and gaps of different widths. Added Roman arcades and neon conduits between temples.
- Added acceleration, coasting, and downhill sliding. Horizontal momentum carries through jumps.
- Added a looping synth score and sound effects for movement, combat, and milestones, with a mute control for both.

### Project documentation

- Added a README with launch instructions, controls, gameplay, and a source overview.
- Added this changelog and recorded the workflow for documenting, committing, and pushing future game updates.

### Initial playable level

- Built eight uphill terraces and seven gaps in a cyberpunk Greco-Roman setting.
- Gave Sisyphus an exoskeleton, a rechargeable rocket booster, and a sledgehammer.
- Added melee guards, projectile turrets, and flying drones.
- Added a midpoint checkpoint, armor and boost indicators, a summit finish, and keyboard and touch controls.
- Pushed the initial game to GitHub in commit [`e94ca70`](https://github.com/AndyZhou3042/Sisyphus-Ascent/commit/e94ca706ac1a757af2570a90a820162751591dfe).
